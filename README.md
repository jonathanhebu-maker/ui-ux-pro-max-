# חסד סטוק – שלהבת חנות המפעל 🛒

אפליקציית חנות אונליין בעברית (RTL) בסגנון "חנות מפעל / סטוק": קטלוג מוצרים לפי
קטגוריות, חיפוש, עגלת קניות, השלמת הזמנה בוואטסאפ, עמוד סניפים ומשלוחים ושאלות
נפוצות.

> העיצוב, התוכן והמיתוג באתר הם מקוריים וניתנים להתאמה מלאה ללקוח – שם, לוגו,
> צבעים, מוצרים ותנאי משלוח.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build   # הפלט נוצר בתיקיית dist/
npm run preview
```

הפלט סטטי לחלוטין – אפשר לפרוס בכל אחסון סטטי (Netlify, Vercel, GitHub Pages,
אחסון רגיל).

## מה מתאימים ללקוח

| מה | איפה |
| --- | --- |
| שם העסק, טלפון, וואטסאפ, אימייל | `src/config.ts` |
| סניפים ושעות פתיחה | `src/config.ts` → `branches` |
| תנאי משלוח (מינימום, דמי משלוח, משלוח חינם) | `src/config.ts` → `shipping` |
| קטגוריות ומוצרים (שם, מחיר, מבצע, תמונה) | `src/data/products.ts` |
| צבעי המותג והטיפוגרפיה | `src/styles.css` (משתני `:root`) |
| כותרות SEO ותיאור האתר | `index.html` |

### תמונות מוצר

לכל מוצר יש כרגע אייקון צבעוני כ-placeholder. כדי להציג תמונה אמיתית: שימו את
קובץ התמונה ב-`public/images/` והוסיפו למוצר שדה
`image: '/images/שם-הקובץ.webp'` ב-`src/data/products.ts`.

## מערכת משתמשים וניהול (שלב 2)

- **הרשמה ואישור מנהל**: לקוח נרשם (שם, טלפון, אימייל) → המנהל מאשר, משייך
  קטגוריית לקוח, והמערכת מייצרת שם משתמש + סיסמה ו"שולחת" ב-SMS ומייל
  (דמו – נרשם ביומן ההודעות; בפרודקשן מחברים ספק שליחה אמיתי).
- **קטגוריות לקוח דינמיות**: המנהל מגדיר קטגוריות (שם + הנחת בסיס) בהגדרות,
  והנחה ספציפית פר־מוצר במסך "מוצרים והנחות".
- **מק"ט**: לכל מוצר מק"ט שמוצג למנהל בלבד ונשמר בכל הזמנה לאימות – לא נחשף ללקוח.
- **מע"מ**: אחוז מע"מ מוגדר בהגדרות; בעגלה ובהזמנה מוצג "סה\"כ כולל מע\"מ (X%)"
  + רכיב המע"מ.
- **תשלום**: מזומן / אשראי (דף סליקה דמו – מתחברים ל-Grow/Tranzila בהמשך) / צ'ק.
- **התראות ותזכורות**: פעמון התראות ללקוח ולמנהל; תזכורות אוטומטיות (SMS+מייל דמו)
  לעגלה נטושה, לייק ללא רכישה ותשלום אשראי שלא הושלם. זמני התזכורות בהגדרות.
- **אנליטיקות מנהל**: מכירות לפי מוצר מפולח לפי קטגוריית לקוח, הכנסות לפי קטגוריה,
  אמצעי תשלום, לקוחות מובילים (כללי או פר־מוצר), סטטוס לקוחות ותזכורות,
  ומה קנה כל לקוח. כפתור "יצירת נתוני דמו" ממלא נתונים לצפייה בגרפים.

**כניסת מנהל (דמו)**: שם משתמש `admin`, סיסמה `admin1234` – להחליף לפני עלייה לאוויר.

> הנתונים נשמרים כרגע ב-localStorage (דמו מלא ללא שרת). לפני השקה אמיתית
> מחברים שרת (Supabase/Firebase/API) – שכבת הנתונים מרוכזת ב-`src/db.ts`
> כך שההחלפה נקודתית.

## זרימת הזמנה

1. הלקוח מוסיף מוצרים לעגלה (נשמרת ב-localStorage).
2. בעמוד "השלמת הזמנה" בוחר משלוח / איסוף עצמי וממלא פרטים.
3. ההזמנה נפתחת כהודעת וואטסאפ מסודרת למספר העסק – אין צורך בשרת או בסליקה.

כללי המשלוח (מינימום הזמנה למשלוח, דמי משלוח, משלוח חינם מעל סכום) נאכפים
אוטומטית בעגלה ובצ'קאאוט לפי ההגדרות ב-`src/config.ts`.

## טכנולוגיות
